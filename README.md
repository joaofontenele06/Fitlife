# 💚 FitLife

> Seu hub central de saúde — calcule IMC, TMB e controle sua hidratação diária.

## Sobre

Projeto feito com HTML, CSS e JavaScript puros (sem frameworks) para praticar:
manipulação do DOM, validação de formulários, variáveis CSS, layout com
Grid/Flexbox e organização de um projeto com múltiplas páginas.

## Estrutura

```
fitlife/
├── index.html
├── css/
│   ├── styles.css
│   └── water.css
├── js/
│   ├── imc.js
│   ├── tmb.js
│   └── water.js
└── pages/
    ├── imc.html
    ├── tmb.html
    └── water.html
```

## Como usar

1. Baixe/extraia a pasta do projeto.
2. Abra `index.html` no navegador (ou use a extensão "Live Server" no VS Code).
3. Navegue entre as ferramentas pelo menu superior.

Não requer instalação, dependências ou servidor.
